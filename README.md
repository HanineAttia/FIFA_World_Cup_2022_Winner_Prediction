# 🏆 FIFA World Cup 2022 — Historical Analysis & Winner Prediction

> End-to-end data science project analyzing World Cup history from 1930 to 2022
> and predicting the 2022 tournament winner using Machine Learning.

---

## 📌 Project Overview

This project combines historical analysis and machine learning to predict the FIFA 
World Cup 2022 winner. It simulates the full tournament bracket — from group stage 
to the final — using XGBoost trained on historical match data, FIFA rankings, 
and team performance scores.

**Predicted Winner : 🇫🇷 France**
